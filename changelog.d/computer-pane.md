### Added

- A new Screen pane in the side panel shows what an agent does with Computer Use on this computer: a live picture of the window that it works in (about once a second, also while another window covers it), what it does now, a Stop button, and the steps of the turn. The pane opens beside the chat when the agent starts to use an app, once for each turn. After the turn it keeps the last picture, dimmed. It shows for agents on this computer only, not on a joined server or in the web client.
