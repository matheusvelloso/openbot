### Added

- A "Messaged" or "Message from" line in a chat has a new button that opens all messages between the two agents in the side panel, oldest first. You stay in the chat. Each message has links that open it in the chat of either agent. On a joined server, the server must also be on this version.

### Changed

- The agent name on a "Messaged" or "Message from" line now opens the other agent's chat at that message, not at its latest message. An answer that runs in a side thread of the other agent opens that side thread.
- A message that an agent sends to another agent from a side thread now also shows in the agent's own chat. Before, only the other agent's chat showed it.
- When an agent starts to use the browser in the chat that you have open, the Browser pane opens beside the chat, so you see the pages that the agent opens on this computer. It opens once for each turn: if you close it, it stays closed until the next turn uses the browser.
